# RuralLink

O **RuralLink** é uma plataforma desenvolvida para conectar diretamente **produtores rurais** a **compradores**, como restaurantes, mercados, hotéis e outros estabelecimentos.

A plataforma permite que produtores anunciem seus produtos disponíveis, informando detalhes como quantidade e preço, enquanto compradores podem encontrar produtos e realizar negociações diretamente com os fornecedores.

## Objetivo

O principal objetivo do RuralLink é **aproximar produtores e compradores**, reduzindo a dependência de intermediários.

Dessa forma, buscamos contribuir para que:

- Produtores tenham mais facilidade para divulgar seus produtos;
- Restaurantes e mercados encontrem fornecedores diretamente;
- Produtores tenham maior possibilidade de receber um valor mais justo pelos seus produtos;
- Compradores possam negociar diretamente com quem produz.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express

## Como funciona

### Produtor
O produtor pode cadastrar e anunciar os produtos que possui disponíveis para venda.

### Comprador
Restaurantes, mercados e outros estabelecimentos podem visualizar os produtos disponíveis e encontrar produtores para realizar negociações diretamente.

## Problema

Muitos produtores rurais dependem de intermediários para conseguir comercializar seus produtos. Isso pode diminuir a margem recebida pelo produtor e aumentar o preço final para o comprador.

## Solução

O RuralLink busca criar uma conexão mais direta entre quem **produz** e quem **compra**, facilitando a divulgação dos produtos e a negociação entre as partes.

## Projeto

Projeto desenvolvido com foco em criar uma solução tecnológica para aproximar produtores rurais e compradores profissionais.
